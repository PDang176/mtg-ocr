# Magic the Gathering OCR Classifier

## Prerequisites

1. Set up Postgresql for your device
2. Install latest version of Python

## Setup

1. Set up python venv
2. Install python libraries using `pip install -r requirements.txt`
3. Initialize .env file using template
4. Set up Postgresql Database
    - Download oracle bulk data set from [Scryfall](https://scryfall.com/docs/api/bulk-data)
    - Move bulk data to json folder and rename to `scryfall_data.json`
    - Run create_database.py

## Usage

1. Run ocr_pipeline.py for results
2. Run tests/edgetest.py for use with video feed

## Folder Structure
1. Database
    - card_loader.py: Load cards from PostgreSQL
    - create_database.py: Initialize PostgreSQL database
2. Images
    - Store images used for testing and other output results
3. Json
    - Folder for storing JSON outputs
    - Contains .gitignore as fiels aren't needed for storage and can be regenerated by rerunning the program
4.  Models
    - Contains models necessary for RapidOCR offline use
5. Processors
    - image_processor.py: Detect images given real world image / video frame and crops card name from images
    - rapidocr_processor.py: Extract text from given image
6. Tests
    - croptest.py: Used for testing out proper crop dimensions of images
    - edgetest.py: Used to test real world video feed usage with model
7. Root
    - card_classifier.py: Classifies card given name
    - config.py: Used for setting up PostgreSQL database
    - env.txt: Template for creating .env file
    - ocr_pipeline.py: Primary executable for running against randomly generated bulk data
    - requirements.txt: Used to pip install necessary libraries
